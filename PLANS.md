# PLANS.md

This file tracks major implementation plans for Sovereign Mission Control.

Use this file for large changes affecting:

- database schema
- multiple pages
- agent architecture
- workflow logic
- safety systems
- diagnostics
- integrations
- deployment
- major UI redesigns

Each plan must include:

1. Objective
2. Current state
3. Target state
4. Files likely affected
5. Implementation phases
6. Risks
7. Test plan
8. Rollback plan
9. Completion checklist

Codex must not use planning as an excuse to avoid implementation.

Plans should stay short, useful, and current.
