# AGENTS.md

Operating laws for this repository:

1. Do not stop at planning when implementation is possible.
2. Inspect the repository before changing files.
3. Reuse existing stack and conventions when present.
4. If the repository is empty, create a clean runnable project from scratch.
5. Prefer local-first architecture, readable code, SQLite/local storage, clear config, and safe defaults.
6. Never hardcode secrets.
7. Never fake integrations, tests, tool access, or completed work.
8. Never delete or overwrite user work without clear need and explicit safety.
9. Run available install, lint, typecheck, test, and build commands when practical.
10. Fix errors discovered during checks.
11. Report exactly what changed, what commands were run, what passed, what failed, and how to run the app.
12. For risky actions, require approval.
13. Build working software, not placeholder-only mockups.
14. Prefer stability, usability, diagnostics, logging, and clean architecture over flashy unfinished features.
